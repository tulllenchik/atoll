# Атолл

Мобильное приложение умного дома для одной квартиры. Клиент собран на React и Vite: обзор приборов, списки, карточки, сценарии и формы с проверкой. Состояние хранится в браузере.

Отчёт по двум практическим работам лежит в файле `Отчет Атолл.docx`.

## Запуск

```bash
cd praktika-1
npm install
npm run dev
```
