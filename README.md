# Атолл

Мобильное приложение умного дома для одной квартиры. В нём обзор приборов, списки, карточки, сценарии и формы. Каталог квартиры загружается из REST-ресурса, температура и влажность датчика — из Open-Meteo. Правки после загрузки хранятся в браузере.

Набор частей экрана лежит в файле `UI-кит Атолл.html`.

## Запуск

```bash
npm install
npm run dev
```

Адрес разработки: `http://127.0.0.1:5173/`

Учебные состояния для снимков:

- `http://127.0.0.1:5173/?demo=error` — обрыв загрузки каталога
- `http://127.0.0.1:5173/?demo=empty` — каталог пришёл, приборов нет

## Сборка и публикация

```bash
npm run build
npm run preview
```

Папка `dist` — production-сборка. Её можно выложить на GitHub Pages или Vercel. Для GitHub Pages в корне репозитория задайте `VITE_BASE=/имя-репозитория/` на время сборки.

После публикации в отчёт нужно положить:

- ссылку на GitHub-репозиторий;
- этот файл `README.md`;
- ссылку на опубликованное приложение.

## Функциональная проверка

1. Маршруты: обзор, устройства, карточка, формы, сценарии.
2. Формы: слишком короткое имя, пустая заметка, сценарий без приборов.
3. CRUD: создать, изменить, удалить прибор и сценарий.
4. API: при обычном запуске приходит каталог и строка «На улице …°».
5. Ошибка: `?demo=error`, кнопка «Повторить».
6. Пусто: `?demo=empty`, кнопка «Добавить устройство».
7. Адаптив: колонка не шире 440 px, поля 16 px, нижние вкладки с учётом безопасной зоны.
8. Сценарии «Вечер» и «Никого нет», затем ручной тумблер снимает активный сценарий.
